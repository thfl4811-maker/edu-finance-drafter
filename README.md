# 품의서 작성기 무과금 통합 최종본

## 포함 기능
- 물품 구입 품의
  - 견적서 업로드: XLSX, XLS, CSV, PDF, 이미지
  - 브라우저 자동 품목 추출
  - 공급가액·부가세·총액 감지
  - 부가세 자동 판단 또는 사용자 직접 선택
  - 사용자가 표를 수정하고 최종 확정
  - 확정된 값만 실제 에듀파인 `품목내역(통합).xls` 원본 서식에 입력
  - 물품 구입 품의서 제목·본문 작성 및 복사
- 업무추진비·협의회 품의
  - 참석 인원 × 1인당 단가 자동 계산
  - 협의회 품의서 제목·본문 작성 및 복사

## 중요
- `public/품목내역(통합).xls`는 사용자가 제공한 66,048바이트 실제 원본 파일입니다.
- API 키와 서버 AI를 사용하지 않습니다.
- 다운로드할 때 견적서를 다시 분석하지 않고, 사용자가 최종 확정한 화면 값을 사용합니다.
- 브라우저용 SheetJS로 레거시 `.xls`를 수정하므로 실제 에듀파인 업로드 환경에서 1회 검증이 필요합니다.
