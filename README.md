# 품의서 작성기

학교 교사가 견적서를 업로드해 에듀파인 업로드용 `품목내역(통합).xls`와 물품 구입 품의서 초안을 함께 만드는 웹앱입니다.

## 주요 기능

- 물품 구입 품의
  - XLSX, XLS, CSV, PDF, PNG, JPG, WEBP 견적서 업로드
  - 품목명·규격·단위·수량·단가 자동 추출
  - 표에서 직접 확인·수정
  - 수량 × 단가 자동 검산
  - 등록된 에듀파인 `품목내역(통합).xls` 형식으로 다운로드
  - 같은 견적서를 활용한 품의서 제목·본문 자동 작성
- 업무추진비·협의회 품의
  - 일시·장소·협의사항·참석자·단가 입력
  - 소요예산 자동 계산
  - 공문서 형식의 품의서 초안 생성

## 배포

1. 이 폴더 전체를 GitHub 저장소에 업로드합니다.
2. Vercel에서 해당 저장소를 Import합니다.
3. Framework Preset은 `Vite`, Root Directory는 `./`로 두고 Deploy합니다.

별도의 API 키나 환경변수는 필요하지 않습니다.

## 중요 파일

- `public/품목내역(통합).xls`: 에듀파인 최종 내려받기 기준 서식
- `src/main.js`: 견적서 분석, 엑셀 변환, 품의서 작성 기능
- `src/style.css`: 화면 디자인

## 참고

스캔 PDF와 사진은 브라우저에서 OCR로 분석하므로 파일이 선명할수록 정확도가 높습니다. 자동 추출 후 반드시 표를 확인하고 필요한 부분을 수정한 뒤 내려받아 사용하세요.


## 1.1 수정사항
- 합계·총계·소계·공급가액·부가세 행은 품목에서 제외
- 공급가액과 부가세가 분리된 견적서는 부가세 포함 단가와 금액으로 변환
- 최종 합계가 견적서 총액과 일치하도록 검산
- 에듀파인 품목내역(통합).xls 헤더/열 순서 고정
- Vercel 정적 파일 경로 수정
