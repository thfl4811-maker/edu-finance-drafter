# 품의서 작성기 — API 키 없는 브라우저형

## 핵심 동작
- 엑셀·PDF·사진 견적서를 브라우저에서 분석합니다.
- 자동 인식 결과를 사용자가 직접 수정합니다.
- 수정 후 `이 내용으로 최종 확정`을 눌러야 다운로드할 수 있습니다.
- 다운로드할 때 다시 분석하지 않고 확정된 화면 값을 그대로 사용합니다.
- `품목내역(통합).xls` 원본 서식의 네 열만 사용합니다.
  - A열 내용
  - B열 규격
  - C열 수량
  - D열 예상단가
- 합계·총계·공급가액·부가세·업체정보·추가 시트는 넣지 않습니다.

## 배포
기존 GitHub 저장소의 파일을 이 폴더 구조로 교체하고 커밋하면 Vercel이 자동 배포합니다.

## 주의
브라우저에서 레거시 `.xls`를 다시 저장하는 방식이므로, 실제 에듀파인 업로드 성공 여부는 최초 1회 테스트가 필요합니다. 업로드가 거부되면 생성 파일과 원본 파일을 함께 비교해 서버 방식으로 전환해야 합니다.
